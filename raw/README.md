# raw/（未加工の元データ）

組織で言えば「会議の文字起こし・チャット・メール」の取り込み口にあたるフォルダです。
ここに置いた元データを、AIが読み取って `areas/` 配下の該当ファイルに整理・反映していきます。

```
raw/
├── sessions/     AIとの会話ログ（自動生成。手で編集しない）
├── memory/       AIが自動で作った記憶ファイルの写し
├── attachments/  画像から読み取った情報の書き起こし
└── （その他）     手で置いたメモ・文字起こしなど
```

## sessions/ — AIとの会話ログ

`tools/import-claude-sessions.py` が、Claude Code のセッションログ（`~/.claude/projects/**/*.jsonl`）から
**会話部分だけ**を抽出して生成します。

```
python tools/import-claude-sessions.py
```

ファイル名は `YYYY-MM-DD_プロジェクト名_セッションID.md`。
再実行すると同じファイルが上書き更新されるので、続いているセッションは何度でも取り込み直せます。
**手で編集しても次回の実行で消えます。**

### 何を残し、何を捨てているか

目的は「アーカイブ」ではなく「**文脈の継承**」です。
どう考え、何を好み、なぜそう決めたか——それが分かる情報だけを残します。

| 残すもの | 捨てるもの |
|---|---|
| 人間とAIの**発言（原文のまま）** | ツールの出力（コマンド結果、読んだファイルの中身） |
| ツール操作の**1行の記録**（何をしたか） | 書いたコードやファイルの本文 |
| セッションのタイトル・日時・プロジェクト | スクリーンショット画像 |
| | システムが会話に差し込む注記 |

書いたコードそのものを残さないのは、**それがリポジトリ側に既にあり、なくてもAIが作り直せるから**です。
一方で「なぜその作りにしたか」は会話にしか残らないので、そちらを優先します。

実測では、元のログ 13.2MB のうち残るのは 0.27MB（**2.1%**）でした。
内訳は、スクリーンショットが全体の78%、ツールの入出力が20%、実際の発言は2.4%です。

### 秘密情報の扱い

取り込み時に、認証情報らしき文字列を自動で `[伏字:種別]` に置き換え、実行結果の最後に必ず報告します。

報告が出た場合、それが**実物だったなら、ファイルから消すだけでは不十分で、発行元での失効・再発行が必要**です
（Git の履歴からは消せないため）。

なお、ツールの出力を捨てている副次効果として、**秘密情報が混入する経路の大半が最初から塞がっています。**

## attachments/ — 画像から読み取った情報

**画像そのものは保存しません。** 実測では会話ログ全体の 77.7% を画像が占めていました（12枚で5.68MB）。
保存すると本文が埋もれます。

代わりに、画像から読み取った情報を `descriptions.json` にテキストで書き起こします。
`sessions/` は自動生成されるため直接書き込めないので、取り込み時にこのファイルを参照して該当箇所へ差し込みます。

キーの形式は `"<セッションIDの先頭8文字>|<タイムスタンプの先頭19文字>"`。

### 何を書き、何を書かないか

書く基準は「**後からその画像なしで、同じ判断を再現できるか**」。
エラー画面ならメッセージの文言、設定画面なら選択した項目、UIなら崩れている箇所。
見た目の描写ではなく、判断に効く事実を書きます。

**書かないもの**

- 認証コード・ワンタイムコード
- IPアドレス、所在地
- ブラウザのブックマークバーやタスクバーなど、作業と無関係な画面の写り込み

素朴に「画像の内容を全部テキストにする」と、これらも一緒に記録されてしまいます。
**画像を捨てても、そこから起こしたテキストが同じ問題を持ち込む**という点に注意してください。

## memory/ — AIの記憶ファイル

AIがセッションをまたいで覚えておくために自分で書いたファイル（`~/.claude/projects/*/memory/`）の写しです。
同じスクリプトで同期されます。すでに「加工済み」の知識に近い形をしているので、`areas/` に育てる際の元ネタになります。

## 手で置くファイルについて

- 編集・要約せず、原則そのまま（元の形）で保存する
- ファイル名は `YYYY-MM-DD_内容の概要.md` のように日付を先頭につけると管理しやすい
- ここも当然、組織の機密情報・第三者の個人情報は対象外（`AGENTS.md` 0. を参照）
